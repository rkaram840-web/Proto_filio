MARIAM ADEL — PORTFOLIO WEBSITE
================================

FILES
- index.html: Main one-page portfolio.
- style.css: Responsive styling and layout.
- assets/mellow-coffee.svg: Custom project preview illustration.
- assets/bloom-skincare.svg: Custom project preview illustration.
- assets/nook-studio.svg: Custom project preview illustration.

HOW TO OPEN
1. Extract the ZIP file to a folder.
2. Open the extracted folder.
3. Double-click index.html. It should open in your browser.
4. Keep style.css and the assets folder beside index.html; do not move them separately.

NOTES BEFORE PUBLISHING
- The portfolio content and projects are sample concepts based on the supplied brief.
- Replace mariam.adel.design@example.com with the real email.
- Replace the Behance and LinkedIn placeholder URLs with the real profile links.
- Google Fonts are loaded online. If offline, the page will use the fallback fonts.
- To publish it and share a link, upload the folder to a static hosting service (for example GitHub Pages or Netlify).

TECHNICAL DETAILS
- HTML5 + CSS3 only. No backend, CMS, JavaScript, or contact form processing.
- Responsive layouts for mobile, tablet, and desktop.
- Accessible navigation labels, alt text, and keyboard focus styling.
